| [Romantická detektivka](https://vojtechmatousek-oss.github.io/romanticka-detektivka/) | Romantismus v malířství |

## Jak přidat novou hru
1. Nový veřejný repozitář s hrou jako `index.html` (+ obrázky).
2. V něm **Settings → Pages → Branch: main, / (root) → Save**.
3. Tady v `index.html` zkopírovat jeden blok v seznamu `GAMES` a přepsat údaje. Obrázek na kartu nahrát do `covers/`.
4. **Commit changes**. Za chvíli je hra na rozcestníku.

Návod pro učitele je přímo na stránce pod tlačítkem **ℹ Pro učitele**.
